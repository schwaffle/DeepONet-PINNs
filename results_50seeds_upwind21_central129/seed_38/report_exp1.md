# Эксп. 1 — PINN-Raissi vs M1 PI-DeepONet

## Исследовательский вопрос
Сравнение однофидельной обратной PINN с составной мультифидельной PI-DeepONet для идентификации гауссова источника в двумерном уравнении адвекции-диффузии.

## Методы
- PINN-Raissi: полносвязная сеть с активацией tanh; обучаемые ограниченные параметры источника; оптимизация Adam, затем SciPy L-BFGS-B.
- M1 PI-DeepONet: LF modified DeepONet + линейный HF DeepONet + нелинейный HF modified DeepONet; HF-выход является суммой выходов линейного и нелинейного блоков.
- MPINN-v2 исключён из данного сравнения.

## Протокол данных и уровней точности
LF-симуляции используют сетку 21×21; HF-симуляции — сетку 129×129. В обоих случаях применяется схема центральных разностей. Целевой источник исключён из ансамбля LF-параметрических функций. Обратное HF-обучение использует 80 зашумлённых наблюдений при noise_fraction=0.005. Чистые тестовые точки берутся из всех сохранённых HF grid-time точек, исключая точные совпадения координата-время с наблюдениями. Отдельная прореженная сетка используется только для визуализации.

## Целевая функция
Для M1 сохранены шесть членов из Howard et al. (2023), Eq. (15): физика, LF-данные, регуляризация нелинейной branch-части, регуляризация LF-ветви, начальное условие и граничное условие. Поскольку данная задача является обратной с разреженными зашумлёнными HF-измерениями, добавлен седьмой, специфичный для задачи член λ_obs L_HF-observation. Тот же observation-loss используется в PINN-Raissi. Это явное расширение Eq. (15), а не утверждение, что Eq. (15) содержит наблюдательный член.

## Обучение и предотвращение утечек
Чистые тестовые значения не используются в обучении, масштабировании, выборе гиперпараметров или ранней остановке. Масштаб концентрации вычисляется только по зашумлённым тренировочным наблюдениям. Разбиение LF train/validation производится по целым реализациям источника. Одни и те же HF-наблюдения, collocation-точки и выборки boundary/initial используются для обоих методов внутри каждого seed. L-BFGS-B использует фиксированные collocation, BC, IC и LF mini-batch точки на всём протяжении closure evaluations.

## Текущие ограничения
В качестве HF-модели используется конечно-разностный солвер проекта, а не WRF-Chem. Связывание с WRF-Chem, калибровка времени выполнения (планируемая дорогая HF-стоимость около 1/5 реального времени), мульти-сидовая статистика, cross-scheme сравнение (central vs upwind) и физическая валидация по данным атмосферной химии остаются задачами на будущее.
